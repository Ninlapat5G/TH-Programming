# TH-Programming

> ภาษาโปรแกรมที่เขียนเป็น **ประโยคภาษาไทยติดกันตามธรรมชาติ** แล้วคอมไพล์เป็น Python ก่อนสั่งทำงาน

```
แสดง "สวัสดีชาวโลก!"                       →   print("สวัสดีชาวโลก!")
คะแนนเท่ากับ 10                            →   คะแนน = 10
มีเงิน 500 บาท                             →   เงิน = 500
ให้ราคารวมเป็นราคาคูณจำนวนชิ้น              →   ราคารวม = ราคา * จำนวนชิ้น
ถ้าคะแนนมากกว่าหรือเท่ากับ 80 แล้วแสดง "ผ่าน"  →   if คะแนน >= 80:
                                                 print("ผ่าน")
```

**เขียนตามหลักการเขียนภาษาไทยได้ตรง ๆ** — คำในวลีเดียวกันเขียนติดกัน
เว้นวรรคหน้าตัวเลขและข้อความ เว้นระหว่างอนุประโยค เหมือนเขียนเรียงความ

คอมไพเลอร์ตัดคำไทยให้เอง การเว้นวรรคจึงเป็นเรื่องของความอ่านง่ายล้วน ๆ
ไม่กระทบความหมาย

```
คะแนนเท่ากับ 10       ←  เหมือนกันทุกประการ  →   คะแนนเท่ากับ10
```

ไม่ต้องใช้สัญลักษณ์แปลก ๆ **และไม่ต้องรู้จัก Python เลย**

## 1. ติดตั้งและเริ่มใช้งาน

สิ่งที่ต้องมีอย่างเดียวคือ **Python 3.8 ขึ้นไป** (ไม่ต้องติดตั้งไลบรารีใด ๆ เพิ่ม)

ดับเบิลคลิกไฟล์

```
install.bat
```

```bat

```

```bash

```


### ใช้งานโดยไม่ติดตั้งอะไรเลย

ภาษานี้ไม่มี dependency ใด ๆ **แตกไฟล์แล้วรันได้ทันที** เลือกวิธีไหนก็ได้

**1. `python -m` จากในโฟลเดอร์โปรเจกต์** — ตรงไปตรงมาที่สุด

```bash
python -m thprog examples/demo.th
```

```bash
python -m thprog '2 บวก 3'
```

**2. ตัวสั่งงานใน `bin/`** — ตั้ง `PYTHONPATH` ให้เองเรียบร้อย จะอยู่โฟลเดอร์ไหนก็เรียกได้

```bash
./bin/thprog examples/demo.th
```

```bat
bin\thprog.cmd examples\demo.th
```

**3. ดับเบิลคลิก `run_demo.bat`** (Windows) — เห็นโค้ด ผลการรัน และ Python ที่แปลได้ ครบในหน้าเดียว

**4. เรียกเป็นไลบรารีจากโค้ด Python**

```python
import sys; sys.path.insert(0, "โฟลเดอร์ที่แตกไฟล์ไว้")
from thprog import run_source
run_source('แสดง "สวัสดี"')
```

## 2. คำสั่ง thprog ทั้งหมด

| คำสั่ง | ความหมาย |
|---|---|
| `thprog โปรแกรม.th` | รันเลย (รูปแบบสั้นที่สุด) |
| `thprog '2 บวก 3'` | รันโค้ดสั้น ๆ แล้ว **แสดงค่าให้เลย** ไม่ต้องมีไฟล์ ไม่ต้องใส่ `-c` |
| `... \| thprog -` | รับโค้ดทาง stdin |
| `thprog -i โปรแกรม.th` | รันจบแล้วอยู่ต่อในโหมดโต้ตอบ พร้อมตัวแปรเดิม |
| `thprog รัน โปรแกรม.th` | รัน — ใส่ `-q` เพื่อซ่อนคำเตือน |
| `thprog ใหม่ ชื่อโปรแกรม` | สร้างไฟล์เริ่มต้นให้ |
| `thprog ดูโค้ด โปรแกรม.th` | ดูโค้ด Python ที่คอมไพเลอร์แปลออกมา |
| `thprog แปลง โปรแกรม.th -o out.py` | สร้างไฟล์ `.py` ที่รันเองได้ ไม่ต้องพึ่ง thprog |
| `thprog ตรวจ โปรแกรม.th --stats` | ตรวจอย่างเดียว ไม่รัน พร้อมสถิติการคอมไพล์ |
| `thprog ตรวจ โปรแกรม.th --json` | ตรวจแล้วคืนผลเป็น JSON สำหรับ editor หรือ CI |
| `thprog จัดรูป โปรแกรม.th` | จัดระเบียบการเยื้องและช่องว่างให้เป็นมาตรฐาน |
| `thprog สร้างคลัง str` | สร้างโครงคลังคำไทยจากโมดูล Python |
| `thprog สาธิต` | สาธิตครบวงจร: โค้ด → ผลรัน → Python ที่แปลได้ |
| `thprog โต้ตอบ` | โหมดโต้ตอบทีละบรรทัด (จำตัวแปรข้ามบรรทัด) |
| `thprog ตรวจเครื่อง` | ตรวจความพร้อมของเครื่อง |
| `thprog ช่วยเหลือ` | แสดงวิธีใช้ทั้งหมด |

**คำสั่งย่อยทุกตัวเรียกเป็นภาษาอังกฤษก็ได้** — `run` `show` `build` `check`
`fmt` `new` `mklib` `demo` `repl` `doctor` `help`

ทุกคำสั่งที่รับไฟล์ ใส่ `-O0` เพื่อปิดการปรับให้เหมาะที่สุดได้

### รันโค้ดสั้น ๆ โดยไม่ต้องสร้างไฟล์

`run` `show` `build` `check` รับซอร์สได้สามทาง เหมือนที่ `python` เองรองรับ

```bash
thprog 'แสดง "สวัสดี"'
```

**นิพจน์เดี่ยวจะแสดงค่าให้อัตโนมัติ** — ใช้เป็นเครื่องคิดเลขภาษาไทยได้เลย

```bash
thprog '2 บวก 3'
```

```bash
thprog 'ใช้คลัง คณิต
แฟกทอเรียลของ 20'
```

> โหมดแสดงค่าอัตโนมัติทำงานเฉพาะ `-c` · stdin · REPL เท่านั้น
> **ไฟล์ `.th` ไม่เปิดโหมดนี้** โปรแกรมที่เขียนไว้แล้วจึงทำงานเหมือนเดิมทุกประการ

```bash
cat โปรแกรม.th | thprog -
```

รันจบแล้วอยากเล่นกับตัวแปรต่อ ใส่ `-i`

```bash
thprog -i โปรแกรม.th
```

#### ⚠ เครื่องหมายคำพูดซ้อนกันบน cmd.exe

กับดักที่เจอบ่อยที่สุด — **cmd กินฟันหนูข้างในไปก่อนที่ thprog จะเห็น**

```bat
thprog "แสดง"สวัสดี""
```
```
[TH301] ยังไม่เคยกำหนดค่าให้ตัวแปร "สวัสดี"
```

โปรแกรมได้รับมาแค่ `แสดงสวัสดี` — ข้อความกลายเป็นชื่อตัวแปรไปแล้ว
ไม่ใช่คอมไพเลอร์ผิด แต่คอมไพเลอร์จะช่วยเดาต้นเหตุให้

| พิมพ์ใน cmd | โปรแกรมได้รับ | |
|---|---|---|
| `thprog "แสดง"สวัสดี""` | `แสดงสวัสดี` | ❌ |
| `thprog แสดง"สวัสดี"` | `แสดงสวัสดี` | ❌ |
| `thprog "แสดง 'สวัสดี'"` | `แสดง 'สวัสดี'` | ✅ |
| `thprog "แสดง \"สวัสดี\""` | `แสดง "สวัสดี"` | ✅ |

**วิธีที่ง่ายที่สุดคือใช้ฟันหนูเดี่ยวข้างใน** — โค้ดไทยรับได้ทั้ง `'...'` `"..."`
และอัญประกาศไทย `“...”` จึงสลับกันใช้กับเชลล์ได้เสมอ

```bat
thprog "แสดง 'สวัสดี'"
```

PowerShell กับ bash ใช้ฟันหนูเดี่ยวครอบข้างนอกได้เลย

```bash
thprog 'แสดง "สวัสดี"'
```

> ถ้าโค้ดยาวหลายบรรทัด แนะนำให้เขียนลงไฟล์ `.th` แล้วสั่ง `thprog ไฟล์.th`
> จะไม่ต้องปวดหัวเรื่องเชลล์เลย

### เรียกจากโค้ด Python (ถ้าต้องการ)


## 3. สอนเขียนภาษา

### 3.1 กฎพื้นฐานมีแค่ 2 ข้อ

1. **หนึ่งบรรทัดเล่าเรื่องเดียวจบ** (จะเขียนหลายคำสั่งต่อกันในบรรทัดก็ได้)
2. **บล็อกย่อยเยื้องเข้าไป 4 ช่องว่าง**

**เขียนตามหลักการเขียนภาษาไทย** — คำในวลีเดียวกันติดกัน เว้นวรรคหน้าตัวเลข

```
คะแนนเท่ากับ 10          ← แนะนำ เขียนแบบนี้
ให้ราคารวมเป็นราคาคูณจำนวนชิ้น
ถ้าคะแนนมากกว่าหรือเท่ากับ 80 แล้วแสดง "ผ่าน"
```

การเว้นวรรคไม่กระทบความหมาย ทั้งสามบรรทัดนี้ให้ผลเหมือนกันทุกประการ

```
ให้ราคาเป็น 250
ให้ราคาเป็น250
ให้ ราคา เป็น 250
```

> **ชื่อตัวแปรห้ามมีช่องว่างข้างใน** — เขียน `ราคารวม` ติดกัน ไม่ใช่ `ราคา รวม`
> (เหมือนภาษาโปรแกรมทั่วไป และตรงกับการเขียนภาษาไทยปกติอยู่แล้ว)

**เขียนหลายอนุประโยคในบรรทัดเดียว** คั่นด้วย `แล้ว` `จากนั้น` `หลังจากนั้น` หรือ `;`

```
ให้เงินเป็น 500 แล้วลดเงินลง 45 แล้วแสดงเงิน
มีเงิน 500 บาท ; แสดงเงิน
```

คอมไพเลอร์จะลองอ่านทั้งบรรทัดเป็นคำสั่งเดียวก่อนเสมอ ตัดประโยคเฉพาะตอนที่
อ่านแบบเดียวไม่ได้ — เขียนแบบเดิมจึงไม่มีทางความหมายเปลี่ยน

### 3.4 ตัวแปร

```
ให้ชื่อคนเป็น "สมชาย"
กำหนดให้อายุคือ 20
ตั้งราคาเท่ากับ 250
คะแนน = 90
ส่วนสูงมีค่าเป็น 1.75
เก็บ 100 ไว้ในเงินสด
มีเงิน 500
```

ชื่อตัวแปรเป็นภาษาไทยได้เต็มที่ และเลขไทย `๑๒๓` ใช้ได้ด้วย

**ประโยคบอกเล่า `มี` + หน่วย** — เขียนเป็นประโยคธรรมชาติได้เลย

```
มีเงิน 500 บาท          →  เงิน = 500
มีนักเรียน 30 คน         →  นักเรียน = 30
มีน้ำหนัก 52.5 กิโลกรัม   →  น้ำหนัก = 52.5
ให้เวลาเป็น 90 นาที       →  เวลา = 90
```

หน่วยและลักษณนาม (`บาท` `คน` `ชิ้น` `กิโลกรัม` `นาที` ...) จะถูกตัดทิ้ง
**เฉพาะตอนที่ตามหลังตัวเลขโดยตรง** เท่านั้น คำเหล่านี้จึงยังใช้เป็นชื่อตัวแปร
ได้ตามปกติ

```
ให้ชิ้นเป็น 5            →  ชิ้น = 5     (ไม่ได้ตามหลังตัวเลข จึงเป็นชื่อตัวแปร)
ให้คนเป็น 3 แล้วแสดงคน   →  คน = 3 ; print(คน)
```

ใช้แทนกันได้: `มี` `มีทั้งหมด` `เริ่มด้วย` `เริ่มต้นด้วย`

**เพิ่ม / ลดค่า**

```
เพิ่มคะแนนอีก10        →  คะแนน += 10
ลดเงินลง30            →  เงิน -= 30
เพิ่มจำนวนคน           →  จำนวนคน += 1
บวก5เข้ากับแต้ม        →  แต้ม += 5
ลบ2ออกจากแต้ม         →  แต้ม -= 2
```

### 3.7 เปรียบเทียบและตรรกะ

| `เท่ากับ` `เหมือนกับ` `ตรงกับ` | `==` |

| `และ` `กับ` `อีกทั้ง` | `and` |
| `หรือ` `ไม่ก็` | `or` |
| `ไม่` `ไม่ใช่` `มิใช่` | `not` |

### 3.8 เงื่อนไข

* `ไม่งั้น` = `มิฉะนั้น` `ไม่เช่นนั้น` `นอกจากนั้น` `กรณีอื่น`
* คำลงท้าย `แล้ว` `ก็` `จึง` จะมีหรือไม่มีก็ได้

### 3.13 คำสงวน — ภาษานี้แบ่งเป็น 3 ชั้น

ภาษาไทยไม่มีตัวแบ่งคำ การบอกว่า "คำไหนเป็นของภาษา คำไหนเป็นชื่อที่ผู้ใช้ตั้ง"
จึงสำคัญมาก ภาษานี้ไม่ได้ใช้บัญชีคำสงวนตายตัวแบบภาษาอื่น แต่แบ่งเป็น 3 ชั้น

**ชั้นที่ 1 — คำสงวนแข็ง (ตั้งเป็นชื่อไม่ได้)**

ตัวดำเนินการ (`บวก` `ลบ` `คูณ` `หาร` `เศษ` `และ` `หรือ` `ไม่` `มากกว่า`
`น้อยกว่า` `เท่ากับ` ฯลฯ) และคำขึ้นต้นคำสั่ง (`แสดง` `ให้` `ถ้า` `ฟังก์ชัน`
`คืนค่า` `เรียก` ฯลฯ) — เหมือน `if` `for` ในภาษาอื่นที่ตั้งเป็นชื่อไม่ได้

```
ให้บวกเป็น 3
```
```
[TH207] ข้อผิดพลาดไวยากรณ์ — บรรทัด 1 คอลัมน์ 1
   1 | ให้บวกเป็น 3
     | ^^^^^^
     ↳ "บวก" เป็นคำสงวนของภาษา จึงตั้งเป็นชื่อไม่ได้
     ↳ คำแนะนำ: คอมไพเลอร์เลยอ่าน "ให้บวก" รวมเป็นชื่อเดียว ซึ่งน่าจะไม่ใช่
       สิ่งที่ตั้งใจ — ลองเปลี่ยนเป็น "บวกเลข" หรือ "ค่าบวก"
```

**ชั้นที่ 2 — คำสงวนอ่อน (ตั้งเป็นชื่อได้ ตำแหน่งเป็นตัวตัดสิน)**

คำเชื่อมอย่าง `รอบ` `ครั้ง` `ใน` `ถึง` `จาก` `ด้วย` `เป็น` `แล้ว`
คนไทยเอาไปตั้งชื่อตัวแปรกันเยอะ จึงตั้งได้ตามปกติ — ไวยากรณ์ดูจากตำแหน่ง

```
ให้รอบเป็น 3        →  รอบ = 3          ("รอบ" เป็นชื่อ)
ทำซ้ำ 3 รอบ                              ("รอบ" เป็นคีย์เวิร์ด)
```

**ชั้นที่ 3 — ฟังก์ชันสำเร็จรูป (ตั้งทับได้เลย)**

`ยอดรวม` `ความยาว` `ตัวแรก` ฯลฯ ตั้งเป็นชื่อตัวแปรหรือฟังก์ชันของตัวเองได้
ของผู้ใช้มาก่อนเสมอ

```
ให้ยอดรวมเป็น 3     →  ยอดรวม = 3       (ทับ builtin ได้)
```

> **ชื่อที่มีคำสงวนซ่อนอยู่ข้างในใช้ได้ปกติ** — `ผลบวก` `นับถอยหลัง` `ลดราคา`
> `มีเงิน` ไม่ถูกซอย เพราะการตัดคำถูกตัดสินด้วยไวยากรณ์ ไม่ใช่ด้วยพจนานุกรมล้วน ๆ

### 3.14 นำเข้าไลบรารีของ Python

ภาษานี้คอมไพล์ลง Python อยู่แล้ว จึงเปิดให้ `import` ได้ตรง ๆ
**ไลบรารีทั้งระบบนิเวศของ Python ใช้ได้ทันที โดยไม่ต้องเขียนใหม่เป็นภาษาไทย**

| เขียนแบบไทย | Python ที่ได้ |
|---|---|
| `นำเข้า math` | `import math` |
| `นำเข้า math เป็นคณิต` | `import math as คณิต` |
| `นำเข้า sqrt จาก math` | `from math import sqrt` |
| `นำเข้า sqrt จาก math เป็นราก` | `from math import sqrt as ราก` |
| `นำเข้า sqrt, pi จาก math` | `from math import sqrt, pi` |
| `ใช้ os.path` | `import os.path` |

คำนำเข้าไม่ตายตัว ใช้ได้ทั้ง `นำเข้า` `ใช้` `ใช้ไลบรารี` `ใช้โมดูล` `ขอใช้`
`เรียกใช้ไลบรารี` `โหลดไลบรารี` `import`

**เข้าถึงสมาชิกด้วยจุด เหมือน Python ทุกอย่าง**

```
นำเข้า math
แสดง math.sqrt(2)
แสดง math.pi

ให้ประโยคเป็น "  สวัสดี  "
แสดงประโยค.strip().upper()
```

**การตั้งชื่อไทยให้ของ Python คือวิธีขยายภาษาที่เร็วที่สุด**

ไม่ต้องแก้คอมไพเลอร์เลย เขียนบรรทัดเดียวก็ได้คำสั่งไทยใหม่มาใช้

```
นำเข้า factorial จาก math เป็นแฟกทอเรียล
นำเข้า shuffle จาก random เป็นสับไพ่
นำเข้า median จาก statistics เป็นมัธยฐาน

แสดงแฟกทอเรียล(20)
แสดงมัธยฐาน([72, 85, 91, 58, 77])
```

> **ชื่อโมดูลต้องเป็นอักษรละติน** — ทั้ง stdlib และ PyPI ใช้ ASCII ทั้งหมด
> ถ้าปล่อยให้เป็นภาษาไทย ชื่อจะถูกตัดคำเป็นหลายก้อนแล้วรายงานข้อผิดพลาดผิดจุด
> ใช้ `เป็น` ตั้งชื่อไทยทับทีหลังแทน

ถ้าไลบรารีไม่ได้ติดตั้งไว้ คอมไพเลอร์ **เตือน** แต่ไม่ฟ้องเป็นข้อผิดพลาด
เพราะเครื่องที่นำไปรันจริงอาจมีติดตั้งอยู่

```
[TW105] คำเตือนความหมาย — บรรทัด 1
   1 | นำเข้า pandas
     ↳ ไม่พบไลบรารี "pandas" ในเครื่องนี้
     ↳ คำแนะนำ: ถ้าเป็นไลบรารีภายนอก ต้องติดตั้งก่อนด้วย  pip install pandas
```

> **สิ่งที่คอมไพเลอร์ตรวจไม่ได้** — เนื้อในของโมดูลอยู่นอกความรู้ของคอมไพเลอร์
> `math.sqrtt(2)` จะผ่านการคอมไพล์ แล้วไปพังตอนรันเหมือน Python
> ตัวตรวจชนิดจะถือว่าทุกอย่างที่มาจากไลบรารีเป็น "ไม่ทราบชนิด" แล้วเงียบไว้

### 3.15 คลังคำไทย — ใช้ของ Python โดยไม่ต้องเขียนแบบ Python

#### ปัญหา: ลำดับคำกลับด้านกัน

```
Python     กรรม . กริยา ( )        ประโยค.strip()
ภาษาไทย     กริยา + กรรม            ตัดช่องว่างของประโยค
```

`.strip()` ไม่ได้แค่ดูไม่ไทย แต่**เรียงคำสวนไวยากรณ์ไทย** ทางแก้จึงไม่ใช่ซ่อนจุด
แต่คือ *พลิกรูปการเรียก* — เทคนิคนี้เรียกว่า **UFCS**: `x.f(y)` ≡ `f(x, y)`

#### วิธีใช้: `ใช้คลัง`

```
ใช้คลัง ข้อความ

ให้ประโยคเป็น "  ภาษาไทย เขียนโปรแกรมได้  "
แสดงตัดช่องว่างของประโยค
แสดงอักษรตัวใหญ่ของ "th-programming"
แสดงแยกของตัดช่องว่างของประโยค
แสดงเปลี่ยนในของประโยคด้วย "ไทย" ด้วย "ไท"
```

`ของ` ซ้อนได้ไม่จำกัดชั้น อ่านจากนอกเข้าใน เหมือนวลีภาษาไทยปกติ

```
แสดงความยาวของตัดช่องว่างของประโยค
```

ค่าที่สองขึ้นไปต่อด้วย `ด้วย` จึงไม่ต้องใช้วงเล็บเลย

```
แสดงจัดชิดขวาของ "7" ด้วย 3 ด้วย "0"      →  007
```

**คลังมาตรฐาน 3 ชุด** — `ข้อความ` (24 คำ) · `รายการ` (16 คำ) · `คณิต` (18 คำ)

#### สร้างคำไทยเองด้วย `นำเข้าวิธี`

```
นำเข้าวิธี strip เป็นตัดขอบ
```
```python
def ตัดขอบ(ตัวมัน, *ค่า, **ค่าที่ตั้งชื่อ):
    return ตัวมัน.strip(*ค่า, **ค่าที่ตั้งชื่อ)
```

ได้กริยาไทยที่ใช้ได้กับ**ทุกชนิดที่มีเมธอดนั้น** (duck typing ของ Python ได้มาฟรี)
บรรทัดเดียวก็ขยายภาษาได้ โดยไม่ต้องแตะคอมไพเลอร์

#### คลังคำเป็น "ข้อมูล" ไม่ใช่ "โค้ดคอมไพเลอร์"

คลังคำคือไฟล์ `.th` ธรรมดา อยู่ในโฟลเดอร์ `คลัง/` — **ของผู้ใช้มาก่อนของภาษาเสมอ**

```
คลัง/ของฉัน.th          ← ในโปรเจกต์ของคุณ (ค้นก่อน)
thprog/คลัง/ข้อความ.th    ← คลังมาตรฐานที่ติดมากับภาษา
```

และคลังคำไม่ได้มีแค่การผูกเมธอด — เขียนตรรกะเป็นภาษาไทยเต็ม ๆ ได้

```
สร้างคำสั่งคีย์ทั้งหมดรับพจนานุกรม
    ให้ผลลัพธ์เป็น []
    สำหรับแต่ละคีย์ในพจนานุกรม
        ใส่ท้ายของผลลัพธ์ด้วยคีย์
    คืนค่าผลลัพธ์
```

#### `thprog สร้างคลัง` — ตัวสร้างโครงคลัง

```bash
thprog สร้างคลัง str -o คลัง/ข้อความของฉัน.th
```

อ่านโมดูลด้วย `inspect` แล้วพ่นโครงพร้อมคำอธิบาย เว้นชื่อไทยไว้ให้เติม

```
นำเข้าวิธี center เป็น______      หมายเหตุ center(self, width, fillchar=' ', /) — Return a centered string
```

เปลี่ยนงานจาก *"เขียน wrapper 47 ตัว"* เป็น *"แปลศัพท์ 47 คำ"* — ซึ่งกระจายให้
คนอื่นช่วยได้ ต่างจากการเขียนโค้ด

#### กติกาการตั้งชื่อไทยในคลัง

| กฎ | เหตุผล |
|---|---|
| ห้ามขึ้นต้นด้วยคำที่ใช้ขึ้นต้นคำสั่ง (`แสดง` `ให้` `เพิ่ม` `เติม` `นับ` `ทำ` `ใช้`) | ตัวตัดคำจะกลืนไปเป็นคีย์เวิร์ด ทำให้ใช้ขึ้นต้นประโยคไม่ได้ |
| ห้ามลงท้ายด้วย `ของ` | `ของ` ต้องมาจากจุดที่เรียกใช้ ไม่ใช่จากชื่อ |
| ตั้งให้อ่านเป็น กริยา+กรรม | `ตัดช่องว่างของประโยค` ไม่ใช่ `ประโยคตัดช่องว่าง` |

ชุดทดสอบบังคับกฎเหล่านี้กับคลังมาตรฐานทุกคำ — ศัพท์ทุกตัวต้องใช้ขึ้นต้นประโยคได้จริง

เก็บไว้ที่ `คลัง/ภาพ.th` ในโปรเจกต์ของตัวเอง

## 4. ข้อความผิดพลาด

คอมไพเลอร์ **ไม่หยุดที่ข้อผิดพลาดแรก** แต่กู้คืนแล้วเดินต่อ
เพื่อรายงานทุกจุดในรอบเดียว ทุกข้อความมีรหัส บรรทัด คอลัมน์ และคำแนะนำ

```
[TH301] ข้อผิดพลาดความหมาย — บรรทัด 2 คอลัมน์ 5
   2 | แสดงราค
     |     ^^^
     ↳ ยังไม่เคยกำหนดค่าให้ตัวแปร "ราค"
     ↳ คำแนะนำ: หมายถึง "ราคา" หรือเปล่า?

[TH304] ข้อผิดพลาดความหมาย — บรรทัด 4
   4 | หยุด
     ↳ คำสั่ง "หยุด" ใช้ได้เฉพาะภายในลูป
     ↳ คำแนะนำ: ย้ายเข้าไปในบล็อก ทำซ้ำ / นับ / ตราบใดที่

สรุป: 2 ข้อผิดพลาด · 1 คำเตือน ในไฟล์ โปรแกรม.th
```

### ตารางรหัส

| ช่วงรหัส | ความหมาย | ตัวอย่าง |
|---|---|---|
| `TH1xx` | ระดับตัวอักษร | `TH101` อักขระที่ไม่รู้จัก · `TH102` ปิดคำพูดไม่ครบ |
| `TH2xx` | ระดับไวยากรณ์ | `TH201` ไม่เข้าใจคำสั่ง · `TH203` บล็อกว่าง · `TH207` ตั้งชื่อชนคำสงวน · `TH208` คลังคำมีปัญหา |
| `TH30x` | ชื่อและขอบเขต | `TH301` ตัวแปรไม่รู้จัก · `TH303` จำนวนอาร์กิวเมนต์ไม่ตรง |
| `TH31x` | ชนิดข้อมูล | `TH311` ใช้ตัวดำเนินการผิดชนิด · `TH312` อ้างดัชนีไม่ได้ · `TH313` ส่งค่าผิดชนิดให้ฟังก์ชัน |
| `TH4xx` | ขณะทำงาน | `TH401` เช่น หารด้วยศูนย์ |
| `TW1xx` | คำเตือน | `TW101` เดาคำผิด · `TW103` ตัวแปรไม่ได้ใช้ · `TW104` โค้ดที่เข้าไม่ถึง · `TW105` ไม่พบไลบรารี · `TW106` มีคำไทยให้ใช้อยู่แล้ว |

ข้อผิดพลาดตอนรันจะชี้กลับไปที่ **บรรทัดในไฟล์ .th** เสมอ ไม่ใช่บรรทัดของ Python

```
[TH401] ข้อผิดพลาดขณะทำงาน — บรรทัด 4
   4 | แสดงตัวตั้งหารตัวหาร
     ↳ หารด้วยศูนย์ไม่ได้
     ↳ คำแนะนำ: ตรวจว่าตัวหารเป็นศูนย์หรือไม่ก่อนหาร
```

พิมพ์ผิดเล็กน้อย ระบบเดาให้แล้วรันต่อพร้อมเตือน

```
[TW101] คำเตือนไวยากรณ์ — บรรทัด 1
     ↳ เดาว่า "แสด" น่าจะหมายถึง "แสดง"
```

## 5. สถาปัตยกรรมคอมไพเลอร์

ครบทุกเฟสตามตำราคอมไพเลอร์

```
ไฟล์ .th
  │
  ├─ 1. Lexical Analysis      tokenizer.py   แยกสตริง ตัวเลข เครื่องหมาย ก้อนอักษร
  ├─ 2. Word Segmentation     wordseg.py     ตัดคำไทย → เสนอหลายแบบ (k-best)
  ├─ 3. Normalization         normalizer.py  รวมวลี · ตัดคำเสริม · ตัดหน่วย
  ├─ 4. Sentence Splitting    sentence.py    เสนอขอบเขตประโยคในบรรทัดเดียว
  ├─ 5. Syntax Analysis       parser.py      → AST  (มีการกู้คืนข้อผิดพลาด)
  ├─ 6. Binding / Resolution  analyzer.py    ชื่อนี้หมายถึงอะไร · ขอบเขต · จำนวนค่า
  ├─ 7. Type Checking         typecheck.py   ค่านี้เอาไปทำแบบนี้ได้ไหม
  ├─ 8. Optimization          optimizer.py   พับค่าคงที่ · ลดรูปพีชคณิต · ตัดโค้ดตาย
  ├─ 9. Code Generation       codegen.py     AST → Python + ตารางเทียบบรรทัด
  └─ 10. Execution            pipeline.py    รัน + แปลข้อผิดพลาดกลับเป็นภาษาไทย
```

ทุกเฟสรายงานปัญหาลง `DiagnosticBag` เดียวกัน

### เทียบกับคอมไพเลอร์ระดับโลก

โครงสร้างนี้อ้างอิงจากสถาปัตยกรรมของ **rustc** และ **TypeScript** ทีม TypeScript
ระบุไว้ตรง ๆ ว่าสิ่งที่แยก "คอมไพเลอร์จริง" ออกจาก "ตัวแปลงโค้ดธรรมดา" คือการมี
**ระบบความหมายครบทั้งสองส่วน** — ผูกชื่อ (Binder) แล้วตรวจชนิด (Checker)

| ส่วนประกอบ | rustc | TypeScript | TH-Programming |
|---|---|---|---|
| Lexer | `rustc_lexer` | `scanner.ts` | `tokenizer.py` |
| Parser → AST | `rustc_parse` | `parser.ts` | `parser.py` `expressions.py` |
| Binder / Name resolution | `rustc_resolve` | `binder.ts` | `analyzer.py` `symbols.py` |
| **Checker (ระบบชนิด)** | `rustc_hir_analysis` | `checker.ts` | **`typecheck.py`** |
| Optimizer | MIR passes | — | `optimizer.py` |
| Emitter | `rustc_codegen` | `emitter.ts` | `codegen.py` |
| Diagnostics | `rustc_errors` | `diagnostics` | `diagnostics.py` |

**ส่วนที่ยังไม่มี** (ตั้งใจไม่ทำ เพราะเกินความจำเป็นของภาษาสำหรับผู้เริ่มต้น)
IR หลายชั้นแบบ HIR/MIR · การวิเคราะห์ dataflow บน CFG เต็มรูปแบบ ·
incremental compilation · language server (LSP)

### เสนอ แล้วให้ไวยากรณ์ตัดสิน

ขั้นที่ 2-5 ไม่ได้เดินเป็นเส้นตรง แต่ทำงานร่วมกัน — นี่คือส่วนที่ต่างจาก
คอมไพเลอร์ภาษาอังกฤษ เพราะภาษาไทยไม่มีตัวแบ่งคำ

```
wordseg   เสนอว่า "คำ" อยู่ตรงไหนได้บ้าง      ─┐
sentence  เสนอว่า "ประโยค" จบตรงไหนได้บ้าง    ─┤→  parser เลือกแบบที่แปลได้จริง
```

### ตัวตรวจชนิดข้อมูล (Type Checker)

ภาษานี้ไม่ต้องประกาศชนิด คอมไพเลอร์เดาให้เอง (type inference) แล้วจับการใช้ผิดชนิด
ตั้งแต่ตอนคอมไพล์ แทนที่จะไประเบิดตอนรัน

```
ให้ชื่อเป็น "สมชาย"
แสดงชื่อลบ 1
```
```
[TH311] ข้อผิดพลาดความหมาย — บรรทัด 2 คอลัมน์ 5
   2 | แสดงชื่อลบ 1
     |     ^^^^
     ↳ เอาข้อความไปลบกับจำนวนเต็มไม่ได้
     ↳ คำแนะนำ: ถ้าตั้งใจต่อข้อความ ให้ใช้ ต่อข้อความ([...]) หรือแปลงชนิดก่อน
```

หลักการสำคัญคือ **"ไม่ทราบ ไว้ก่อน"** — เมื่อเดาชนิดไม่ได้ (พารามิเตอร์ของฟังก์ชัน ·
สมาชิกในรายการ · ตัวแปรที่ถูกกำหนดค่าหลายชนิด) จะเงียบ ไม่ฟ้อง
เพราะการฟ้องผิดในภาษาสำหรับผู้เริ่มต้นอันตรายกว่าการปล่อยผ่าน
ตัวตรวจนี้ฟ้องเฉพาะกรณีที่ **ปล่อยไปแล้วพังตอนรันแน่นอน** เท่านั้น

### ผลลัพธ์ที่เครื่องอ่านได้

```bash
thprog check โปรแกรม.th --json
```

คืน JSON ที่มีรหัส · ความรุนแรง · บรรทัด · คอลัมน์ (เริ่มที่ 1) · คำแนะนำ
พร้อม exit code (0 = ผ่าน, 1 = มีข้อผิดพลาด) สำหรับต่อกับ editor หรือ CI

### การกู้คืนข้อผิดพลาด (Error Recovery)

ใช้ **panic-mode recovery ระดับคำสั่ง** — เมื่อบรรทัดใดอ่านไม่ออก
คอมไพเลอร์บันทึกปัญหา ข้ามคำสั่งนั้นทั้งก้อน (รวมบล็อกย่อยของมัน) แล้วอ่านต่อ
จึงรายงานได้ครบโดยไม่เกิดข้อผิดพลาดลูกโซ่ และหยุดรายงานที่ 20 จุดเพื่อไม่ให้ท่วมจอ

### ตารางสัญลักษณ์ (Symbol Table)

ขอบเขตซ้อนกันเป็นลูกโซ่ `โมดูล → ฟังก์ชัน → ฟังก์ชันซ้อน`
แต่ละสัญลักษณ์เก็บ ชนิด · บรรทัดที่ประกาศ · จำนวนพารามิเตอร์ · จำนวนครั้งที่ถูกอ่าน/เขียน
ทำให้ตรวจได้ทั้ง "ใช้ตัวแปรที่ยังไม่ประกาศ" และ "ประกาศแล้วไม่ได้ใช้"

### ตัวปรับให้เหมาะที่สุด (Optimizer)

```
ให้วินาทีต่อวันเป็น60คูณ60คูณ24    →  วินาทีต่อวัน = 86400
ให้ผลเป็นยอดบวก0คูณ1              →  ผล = ยอด
ถ้าเท็จ ... ไม่งั้น ...             →  เหลือเฉพาะกิ่งที่ทำงานจริง
ทำซ้ำ0ครั้ง ...                    →  ตัดทิ้ง
```

ดูจำนวนที่ปรับได้ด้วย `thprog check ไฟล์.th --stats` และปิดด้วย `-O0`
ทุกการแปลงถูกออกแบบให้ **ปลอดภัยเสมอ** ถ้าไม่แน่ใจจะไม่แตะ
(เช่น ไม่พับ `1 หาร 0` เพราะต้องปล่อยให้ฟ้องตอนรัน)

## 6. หัวใจ: การตัดคำภาษาไทย

`ให้ราคารวมเป็นราคาคูณจำนวนชิ้น` ตัดคำได้หลายสิบแบบ แบบไหนถูก?
นี่คือปัญหาที่ยากที่สุดของภาษานี้ แก้ด้วย 5 ชั้น (อ้างอิงแนวทาง `newmm` ของ PyThaiNLP)

**ชั้นที่ 1 — TCC (Thai Character Cluster)**
จำกัดจุดที่ตัดได้ให้เหลือเฉพาะจุดที่ถูกต้องตามหลักการเขียนไทย
ไม่ตัดกลางพยางค์ เช่น `ต` + `ัว`

**ชั้นที่ 2 — Maximal matching ด้วย DP**
หาเส้นทางตัดคำที่ต้นทุนต่ำสุด

```
คำที่รู้จัก    = 0.25
คำที่ไม่รู้จัก = 0.3 + 0.7 × จำนวนกลุ่ม TCC   (+1.0 ถ้าสั้นกว่า 3 ตัวอักษร)
```

| กติกา | ผลที่ได้ |
|---|---|
| `คำที่รู้จัก < ค่าต่อกลุ่มของคำไม่รู้จัก` | คำสั่งไม่ถูกกลืน — `ให้ชื่อ` ไม่กลายเป็นตัวแปรเดียว |
| ค่าปรับคำสั้น | ชื่อไม่ถูกซอย — `ผลบวก` ไม่ถูกซอยเป็น `ผ│ลบ│วก` ทั้งที่ `ลบ` เป็นคำของภาษา |

**ชั้นที่ 3 — ห้ามคำที่ไม่รู้จักสองก้อนติดกัน**
ชื่อสองชื่อวางชิดกันไม่มีความหมายในภาษานี้ กฎเดียวนี้ตัดตัวเลือกขยะทิ้งมหาศาล

**ชั้นที่ 4 — ให้ไวยากรณ์เป็นคนตัดสิน**
ตัวตัดคำไม่ฟันธง แต่ส่งตัวเลือกหลายแบบให้ parser ลองแปลจริง
แล้วเลือกการตีความที่ใช้คีย์เวิร์ดมากที่สุด

```
ฟังก์ชันบวกเลขรับตัวแรกและตัวหลัง

  แบบ ก  ฟังก์ชัน │ บวกเลขรับตัวแรกและตัวหลัง             ← ฟังก์ชันไม่มีพารามิเตอร์
  แบบ ข  ฟังก์ชัน │ บวกเลข │ รับ │ ตัวแรก │ และ │ ตัวหลัง   ← ใช้คีย์เวิร์ดมากกว่า ✔
```

**ชั้นที่ 5 — พจนานุกรมที่เรียนรู้ได้**
ชื่อตัวแปร ฟังก์ชัน พารามิเตอร์ และตัวแปรลูป ถูกจำเข้าพจนานุกรม **ทันทีที่ประกาศ**
(ก่อนอ่านบล็อกย่อยด้วย) บรรทัดถัดไปจึงตัดคำถูกตั้งแต่ครั้งแรก
ยิ่งอ่านโปรแกรมไปเรื่อย ๆ ตัวตัดคำยิ่งแม่นขึ้น

### ชั้น NLP อื่น ๆ

* **คำพ้อง** — `แสดง / พิมพ์ / บอก / โชว์ / รายงาน` หมายถึงคำสั่งเดียวกัน
* **รวมวลี** — `มากกว่า หรือ เท่ากับ` ยุบเป็นตัวดำเนินการ `>=` ตัวเดียว
* **ตัดคำเสริม** — `ว่า ดังนี้ ซึ่ง` หายไปเองโดยไม่กระทบความหมาย
* **คำลงท้ายประโยค** — `ครับ ค่ะ นะ หน่อย` ตัดทิ้ง **เฉพาะท้ายประโยค**
  เพราะคำเหล่านี้เป็นพยางค์แรกของคำไทยทั่วไป ถ้าตัดทุกตำแหน่งจะกินชื่อตัวแปร
  (`คะแนน` → `แนน`)
* **หน่วยและลักษณนาม** — `บาท คน ชิ้น กิโลกรัม` ตัดทิ้ง **เฉพาะเมื่อตามหลังตัวเลข**
  คำเหล่านี้จึงยังใช้เป็นชื่อตัวแปรได้ตามปกติ
* **ความกำกวมตามบริบท** — `เท่ากับ` เป็นได้ทั้ง `=` และ `==` ตำแหน่งในประโยคเป็นตัวตัดสิน
* **ตัดประโยค** — `แล้ว` เป็นได้ทั้ง "จึง" ของเงื่อนไข และตัวคั่นประโยค
  ไวยากรณ์เป็นตัวตัดสินอีกเช่นกัน
* **เดาคำผิด** — พิมพ์ `แสด` แทน `แสดง` ระบบเดาให้พร้อมแจ้งเตือน

ทั้งหมดเป็น NLP เชิงสัญลักษณ์ (rule-based) ไม่ใช้โมเดล ML จึงเร็ว ผลลัพธ์คาดเดาได้
และไม่ต้องติดตั้งอะไรเพิ่ม — คอมไพล์ + รันไฟล์ 60 บรรทัดใช้เวลาราว 0.2 วินาที

## 8. วิธีขยายภาษา

### เพิ่มคำพ้องใหม่ — แก้ `thprog/lang/lexicon.py` ที่เดียว

```python
("PRINT", ["แสดง", "พิมพ์", "บอก", "โชว์", "ป่าวประกาศ"]),   # ← เติมคำท้ายรายการ
```

> ข้อควรระวัง: เลี่ยงสำนวนที่ขึ้นต้นด้วยคำสั่งอื่น เช่น อย่าใส่ `"ให้ผลลัพธ์"`
> เป็นคำพ้องของ `คืนค่า` เพราะจะชนกับ `ให้ผลลัพธ์เป็น...` (กำหนดค่าให้ตัวแปรชื่อ "ผลลัพธ์")

### เพิ่มฟังก์ชันสำเร็จรูป — แก้ `thprog/lang/builtins.py`

```python
BUILTINS = {
    "ตัดคำหน้า": ("_th_lstrip", "lstrip"),   # ชื่อไทย -> (โค้ด Python, ชื่อ helper)
}

HELPERS = {
    "lstrip": ("def _th_lstrip(text):\n    return str(text).lstrip()", ()),
}
```

### เพิ่มรูปประโยคใหม่ — แก้ `thprog/lang/grammar.py`

```python
Pattern("รอสักครู่",
        [Kw("WAIT"), Slot("วินาที", "expr")],
        lambda s, line, body: A.ExprStmt(
            A.Call(A.Name("รอ"), [s["วินาที"]]), line)),
```

รูปประโยคที่เฉพาะเจาะจงกว่า ให้วางไว้บนกว่าในตาราง

### เพิ่มหน่วย/ลักษณนามใหม่ — แก้ `UNITS` ใน `thprog/lang/lexicon.py`

```python
UNITS = {
    "บาท", "กิโลกรัม", "แกลลอน",     # ← เติมคำใหม่ได้เลย
}
```

> ห้ามใส่คำที่เป็นคีย์เวิร์ดอยู่แล้ว เช่น `ครั้ง` `รอบ` (ของคำสั่ง `ทำซ้ำ`)
> หรือ `%` (ตัวดำเนินการหารเอาเศษ)

### เพิ่มตัวคั่นประโยคใหม่ — เติมรหัส `SEQ` ใน `thprog/lang/lexicon.py`

```python
("SEQ", ["แล้ว", "จากนั้น", "หลังจากนั้น", "ต่อจากนั้น", ";", "ถัดไป"]),
```

### ปรับสัญชาตญาณของตัวตัดคำ — แก้ค่าคงที่ใน `thprog/compiler/wordseg.py`

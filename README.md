> ภาษาโปรแกรมที่เขียนเป็น **ประโยคภาษาไทยติดกันตามธรรมชาติ** แล้วคอมไพล์เป็น Python ก่อนสั่งทำงาน

## 2. คำสั่ง thpro ทั้งหมด

| คำสั่ง | ความหมาย |
|---|---|
| `thpro โปรแกรม.th` | รันเลย (รูปแบบสั้นที่สุด) |
| `thpro run โปรแกรม.th` | รัน — ใส่ `-q` เพื่อซ่อนคำเตือน |
| `thpro new ชื่อโปรแกรม` | สร้างไฟล์เริ่มต้นให้ |
| `thpro show โปรแกรม.th` | ดูโค้ด Python ที่คอมไพเลอร์แปลออกมา |
| `thpro build โปรแกรม.th -o out.py` | สร้างไฟล์ `.py` ที่รันเองได้ ไม่ต้องพึ่ง thpro |
| `thpro check โปรแกรม.th --stats` | ตรวจอย่างเดียว ไม่รัน พร้อมสถิติการคอมไพล์ |
| `thpro fmt โปรแกรม.th` | จัดระเบียบการเยื้องและช่องว่างให้เป็นมาตรฐาน |
| `thpro demo` | สาธิตครบวงจร: โค้ด → ผลรัน → Python ที่แปลได้ |
| `thpro repl` | โหมดโต้ตอบทีละบรรทัด (จำตัวแปรข้ามบรรทัด) |
| `thpro doctor` | ตรวจความพร้อมของเครื่อง |
| `thpro help` | แสดงวิธีใช้ทั้งหมด |

ทุกคำสั่งที่รับไฟล์ ใส่ `-O0` เพื่อปิดการปรับให้เหมาะที่สุดได้

### เรียกจากโค้ด Python (ถ้าต้องการ)

```python
from thpro import compile_source, run_source, check_source

run_source('แสดง"สวัสดี"')
print(compile_source('ให้ราคาเป็น250').python)
print(check_source('แสดงตัวที่ไม่มี').summary())
```

### 3.4 ตัวแปร

```
ให้ชื่อคนเป็น"สมชาย"
กำหนดให้อายุคือ20
ตั้งราคาเท่ากับ250
คะแนน=90
ส่วนสูงมีค่าเป็น1.75
เก็บ100ไว้ในเงินสด
```

ชื่อตัวแปรเป็นภาษาไทยได้เต็มที่ และเลขไทย `๑๒๓` ใช้ได้ด้วย

**เพิ่ม / ลดค่า**

```
เพิ่มคะแนนอีก10        →  คะแนน += 10
ลดเงินลง30            →  เงิน -= 30
เพิ่มจำนวนคน           →  จำนวนคน += 1
บวก5เข้ากับแต้ม        →  แต้ม += 5
ลบ2ออกจากแต้ม         →  แต้ม -= 2
```

### 3.5 ชนิดข้อมูล

```
ให้จำนวนนักเรียนเป็น10
ให้ส่วนสูงเป็น1.75
ให้คำทักทายเป็น"สวัสดี"
ให้เปิดร้านแล้วเป็นจริง                    หมายเหตุ จริง / เท็จ
ให้ยังไม่มีข้อมูลเป็นค่าว่าง
ให้รายชื่อเป็น["ก","ข","ค"]
ให้ราคาสินค้าเป็น{"ข้าว":40,"ไข่":5}
แสดงรายชื่อ[0]
แสดงราคาสินค้า["ข้าว"]
```

### 3.8 เงื่อนไข

```
ถ้าคะแนนมากกว่าหรือเท่ากับ80แล้ว
    แสดง"เกรด A"
ไม่งั้นถ้าคะแนนไม่น้อยกว่า70
    แสดง"เกรด B"
ไม่งั้น
    แสดง"ต้องพยายามอีก"
```

* `ถ้า` = `หาก` `ถ้าหาก` `เมื่อ` `ในกรณีที่` `ตรวจสอบว่า` `เช็คว่า`
* `ไม่งั้นถ้า` = `มิฉะนั้นถ้า` `หรือถ้า` `แต่ถ้า` `หรือหาก`
* `ไม่งั้น` = `มิฉะนั้น` `ไม่เช่นนั้น` `นอกจากนั้น` `กรณีอื่น`
* คำลงท้าย `แล้ว` `ก็` `จึง` จะมีหรือไม่มีก็ได้

**เขียนจบในบรรทัดเดียวก็ได้**

```
ถ้ายอดซื้อมากกว่า1000ให้แสดง"ได้ส่วนลด"
ไม่งั้นให้แสดง"ราคาปกติ"
```

**เงื่อนไขซับซ้อน**

```
ถ้าอายุมากกว่า18และมีบัตรแล้ว
    แสดง"เข้าได้"

ถ้าไม่มีบัตรหรืออายุน้อยกว่า15
    แสดง"ต้องมีผู้ปกครอง"
```

### 3.9 ลูป — มี 5 แบบ

**(1) ทำซ้ำตามจำนวนครั้ง**

```
ทำซ้ำ3ครั้ง
    แสดง"สวัสดี"

ทำซ้ำ3ครั้งให้แสดง"สวัสดี"        หมายเหตุ บรรทัดเดียวก็ได้
```

**(2) นับเลขจาก...ถึง...** (รวมเลขปลายทาง)

```
นับรอบจาก1ถึง5
    แสดง"รอบที่",รอบ

นับตัวนับจาก10ถึง1ทีละ-1         หมายเหตุ นับถอยหลัง
    แสดงตัวนับ
```

**(3) วนทีละสมาชิกในรายการ**

```
สำหรับแต่ละผลไม้ใน["แอปเปิ้ล","กล้วย","ส้ม"]
    แสดง"ฉันชอบ",ผลไม้
```

**(4) วนตราบใดที่เงื่อนไขยังจริง**

```
ตราบใดที่เงินมากกว่า0
    แสดง"เหลือเงิน",เงิน
    ลดเงินลง30
```

**(5) วนจนกว่าเงื่อนไขจะเป็นจริง**

```
ทำซ้ำจนกว่านาฬิกาเท่ากับ3
    แสดง"ติ๊ก",นาฬิกา
    เพิ่มนาฬิกา
```

**ควบคุมลูป**

```
หยุด      ออกจากลูปทันที    — หรือ  ออกจากลูป / เลิกทำ / พอแล้ว
ข้าม      ข้ามไปรอบถัดไป    — หรือ  ข้ามรอบนี้ / ไปรอบถัดไป
```

**เพิ่มสมาชิกเข้ารายการ**

```
ให้ตะกร้าเป็น[]
นับดัชนีจาก1ถึง5
    เพิ่มดัชนีคูณดัชนีเข้าไปในตะกร้า
แสดงตะกร้า                        →  [1, 4, 9, 16, 25]
```

### 3.10 ฟังก์ชัน

```
ฟังก์ชันทักทายรับชื่อคน
    แสดง"สวัสดีคุณ",ชื่อคน

ฟังก์ชันบวกเลขรับตัวแรกและตัวหลัง
    คืนค่าตัวแรกบวกตัวหลัง

ฟังก์ชันพื้นที่รับด้านกว้าง,ด้านยาว
    คืนค่าด้านกว้างคูณด้านยาว

ฟังก์ชันชื่อว่าแสดงเมนู
    แสดง"1) เริ่ม"
```

พารามิเตอร์คั่นด้วย `,` หรือ `และ` ก็ได้

**เรียกใช้ได้ 2 แบบ**

```
เรียกทักทายด้วย"สมหญิง"           แบบภาษาพูด
แสดงบวกเลข(3,4)                  แบบวงเล็บ (เอาค่าที่คืนมาใช้ต่อได้)
```

**เรียกซ้อนตัวเอง (recursion)**

```
ฟังก์ชันแฟกทอเรียลรับเลข
    ถ้าเลขน้อยกว่าหรือเท่ากับ1ให้คืนค่า1
    คืนค่าเลขคูณแฟกทอเรียล(เลขลบ1)
```

### 3.11 รับค่าจากผู้ใช้

```
ถาม"คุณชื่ออะไร: "เก็บในชื่อผู้ใช้
ถาม"อายุเท่าไหร่: "เก็บในอายุเป็นตัวเลข
ถาม"ส่วนสูง: "เก็บในส่วนสูงเป็นทศนิยม
```

ถ้าไม่ระบุ `เป็น <ชนิด>` จะได้ข้อความเสมอ
ชนิดที่ใช้ได้: `ตัวเลข` (จำนวนเต็ม) · `ทศนิยม` · `ข้อความ`

### 3.12 ฟังก์ชันสำเร็จรูป

| คำสั่ง | ความหมาย |
|---|---|
| `ความยาว(x)` `ขนาด(x)` `จำนวนสมาชิก(x)` | จำนวนสมาชิก |
| `ตัวเลข(x)` `ทศนิยม(x)` `ข้อความ(x)` | แปลงชนิด |
| `ผลรวม(รายการ)` `ยอดรวม(รายการ)` | บวกทุกตัว |
| `ค่าเฉลี่ย(รายการ)` | ค่าเฉลี่ย |
| `มากสุด(...)` `น้อยสุด(...)` | ค่ามาก/น้อยสุด |
| `ปัดเศษ(x,ตำแหน่ง)` `ค่าสัมบูรณ์(x)` `รากที่สอง(x)` | คณิตศาสตร์ |
| `สุ่ม(1,6)` `สุ่มเลือก(รายการ)` | สุ่ม |
| `เรียงลำดับ(รายการ)` `กลับลำดับ(รายการ)` | จัดเรียง |
| `มีอยู่(รายการ,ค่า)` `หาตำแหน่ง(รายการ,ค่า)` `ลบสมาชิก(รายการ,ค่า)` | จัดการรายการ |
| `ตัวพิมพ์ใหญ่(s)` `ตัวพิมพ์เล็ก(s)` `ตัดช่องว่าง(s)` | ข้อความ |
| `แยกคำ(s)` `ต่อข้อความ(รายการ,ตัวคั่น)` `แทนที่(s,เก่า,ใหม่)` | ข้อความ |
| `ชนิด(x)` `ประเภท(x)` | บอกชนิดข้อมูลเป็นภาษาไทย |
| `ช่วง(เริ่ม,จบ)` | ช่วงตัวเลข |

เรียกแบบภาษาพูดด้วย `ของ` ก็ได้ — `ความยาวของรายชื่อ` = `ความยาว(รายชื่อ)`

> ตั้งชื่อตัวแปรหรือฟังก์ชันซ้ำกับชื่อเหล่านี้ได้ ของผู้ใช้จะมาก่อนเสมอ

### 3.13 คำสงวน

คำที่เป็นตัวดำเนินการ (`บวก` `ลบ` `คูณ` `หาร` `เศษ` `และ` `หรือ` `ไม่`
`มากกว่า` `น้อยกว่า` `เท่ากับ` ฯลฯ) และคำขึ้นต้นคำสั่ง (`แสดง` `ให้` `ถ้า`
`ฟังก์ชัน` `คืนค่า` `เรียก` ฯลฯ) **ใช้เป็นชื่อไม่ได้**
ถ้าเผลอใช้ คอมไพเลอร์จะบอกและแนะนำชื่อใหม่ให้

คำเชื่อมอ่อน ๆ อย่าง `รอบ` `ครั้ง` `ใน` `ถึง` ยังตั้งเป็นชื่อตัวแปรได้ตามปกติ

## 4. ข้อความผิดพลาด

คอมไพเลอร์ **ไม่หยุดที่ข้อผิดพลาดแรก** แต่กู้คืนแล้วเดินต่อ
เพื่อรายงานทุกจุดในรอบเดียว ทุกข้อความมีรหัส บรรทัด คอลัมน์ และคำแนะนำ

```
[TH301] ข้อผิดพลาดความหมาย — บรรทัด 2 คอลัมน์ 5
   2 | แสดงราค
     |     ^^^
     ↳ ยังไม่เคยกำหนดค่าให้ตัวแปร "ราค"
     ↳ คำแนะนำ: หมายถึง "ราคา" หรือเปล่า?

[TH304] ข้อผิดพลาดความหมาย — บรรทัด 4
   4 | หยุด
     ↳ คำสั่ง "หยุด" ใช้ได้เฉพาะภายในลูป
     ↳ คำแนะนำ: ย้ายเข้าไปในบล็อก ทำซ้ำ / นับ / ตราบใดที่

สรุป: 2 ข้อผิดพลาด · 1 คำเตือน ในไฟล์ โปรแกรม.th
```

### ตารางรหัส

| ช่วงรหัส | ความหมาย | ตัวอย่าง |
|---|---|---|
| `TH1xx` | ระดับตัวอักษร | `TH101` อักขระที่ไม่รู้จัก · `TH102` ปิดคำพูดไม่ครบ |
| `TH2xx` | ระดับไวยากรณ์ | `TH201` ไม่เข้าใจคำสั่ง · `TH203` บล็อกว่าง · `TH207` ตั้งชื่อชนคำสงวน |
| `TH3xx` | ระดับความหมาย | `TH301` ตัวแปรไม่รู้จัก · `TH303` จำนวนอาร์กิวเมนต์ไม่ตรง |
| `TH4xx` | ขณะทำงาน | `TH401` เช่น หารด้วยศูนย์ |
| `TW1xx` | คำเตือน | `TW101` เดาคำผิด · `TW103` ตัวแปรไม่ได้ใช้ · `TW104` โค้ดที่เข้าไม่ถึง |

ข้อผิดพลาดตอนรันจะชี้กลับไปที่ **บรรทัดในไฟล์ .th** เสมอ ไม่ใช่บรรทัดของ Python

```
[TH401] ข้อผิดพลาดขณะทำงาน — บรรทัด 4
   4 | แสดงตัวตั้งหารตัวหาร
     ↳ หารด้วยศูนย์ไม่ได้
     ↳ คำแนะนำ: ตรวจว่าตัวหารเป็นศูนย์หรือไม่ก่อนหาร
```

พิมพ์ผิดเล็กน้อย ระบบเดาให้แล้วรันต่อพร้อมเตือน

```
[TW101] คำเตือนไวยากรณ์ — บรรทัด 1
     ↳ เดาว่า "แสด" น่าจะหมายถึง "แสดง"
```

## 5. สถาปัตยกรรมคอมไพเลอร์

ครบทุกเฟสตามตำราคอมไพเลอร์

```
ไฟล์ .th
  │
  ├─ 1. Lexical Analysis     tokenizer.py   แยกสตริง ตัวเลข เครื่องหมาย ก้อนอักษร
  ├─ 2. Word Segmentation    wordseg.py     ตัดคำไทย → เสนอหลายแบบ (k-best)
  ├─ 3. Normalization        normalizer.py  รวมวลี · ตัดคำเสริม · เดาคำผิด
  ├─ 4. Syntax Analysis      parser.py      → AST  (มีการกู้คืนข้อผิดพลาด)
  ├─ 5. Semantic Analysis    analyzer.py    ตารางสัญลักษณ์ · ตรวจขอบเขต · ตรวจชนิดการใช้
  ├─ 6. Optimization         optimizer.py   พับค่าคงที่ · ลดรูปพีชคณิต · ตัดโค้ดตาย
  ├─ 7. Code Generation      codegen.py     AST → Python + ตารางเทียบบรรทัด
  └─ 8. Execution            pipeline.py    รัน + แปลข้อผิดพลาดกลับเป็นภาษาไทย
```

ทุกเฟสรายงานปัญหาลง `DiagnosticBag` เดียวกัน

### การกู้คืนข้อผิดพลาด (Error Recovery)

ใช้ **panic-mode recovery ระดับคำสั่ง** — เมื่อบรรทัดใดอ่านไม่ออก
คอมไพเลอร์บันทึกปัญหา ข้ามคำสั่งนั้นทั้งก้อน (รวมบล็อกย่อยของมัน) แล้วอ่านต่อ
จึงรายงานได้ครบโดยไม่เกิดข้อผิดพลาดลูกโซ่ และหยุดรายงานที่ 20 จุดเพื่อไม่ให้ท่วมจอ

### ตารางสัญลักษณ์ (Symbol Table)

ขอบเขตซ้อนกันเป็นลูกโซ่ `โมดูล → ฟังก์ชัน → ฟังก์ชันซ้อน`
แต่ละสัญลักษณ์เก็บ ชนิด · บรรทัดที่ประกาศ · จำนวนพารามิเตอร์ · จำนวนครั้งที่ถูกอ่าน/เขียน
ทำให้ตรวจได้ทั้ง "ใช้ตัวแปรที่ยังไม่ประกาศ" และ "ประกาศแล้วไม่ได้ใช้"

### ตัวปรับให้เหมาะที่สุด (Optimizer)

```
ให้วินาทีต่อวันเป็น60คูณ60คูณ24    →  วินาทีต่อวัน = 86400
ให้ผลเป็นยอดบวก0คูณ1              →  ผล = ยอด
ถ้าเท็จ ... ไม่งั้น ...             →  เหลือเฉพาะกิ่งที่ทำงานจริง
ทำซ้ำ0ครั้ง ...                    →  ตัดทิ้ง
```

ดูจำนวนที่ปรับได้ด้วย `thpro check ไฟล์.th --stats` และปิดด้วย `-O0`
ทุกการแปลงถูกออกแบบให้ **ปลอดภัยเสมอ** ถ้าไม่แน่ใจจะไม่แตะ
(เช่น ไม่พับ `1 หาร 0` เพราะต้องปล่อยให้ฟ้องตอนรัน)

## 6. หัวใจ: การตัดคำภาษาไทย

`ให้ราคารวมเป็นราคาคูณจำนวนชิ้น` ตัดคำได้หลายสิบแบบ แบบไหนถูก?
นี่คือปัญหาที่ยากที่สุดของภาษานี้ แก้ด้วย 5 ชั้น (อ้างอิงแนวทาง `newmm` ของ PyThaiNLP)

**ชั้นที่ 1 — TCC (Thai Character Cluster)**
จำกัดจุดที่ตัดได้ให้เหลือเฉพาะจุดที่ถูกต้องตามหลักการเขียนไทย
ไม่ตัดกลางพยางค์ เช่น `ต` + `ัว`

**ชั้นที่ 2 — Maximal matching ด้วย DP**
หาเส้นทางตัดคำที่ต้นทุนต่ำสุด

```
คำที่รู้จัก    = 0.25
คำที่ไม่รู้จัก = 0.3 + 0.7 × จำนวนกลุ่ม TCC   (+1.0 ถ้าสั้นกว่า 3 ตัวอักษร)
```

| กติกา | ผลที่ได้ |
|---|---|
| `คำที่รู้จัก < ค่าต่อกลุ่มของคำไม่รู้จัก` | คำสั่งไม่ถูกกลืน — `ให้ชื่อ` ไม่กลายเป็นตัวแปรเดียว |
| ค่าปรับคำสั้น | ชื่อไม่ถูกซอย — `ผลบวก` ไม่ถูกซอยเป็น `ผ│ลบ│วก` ทั้งที่ `ลบ` เป็นคำของภาษา |

**ชั้นที่ 3 — ห้ามคำที่ไม่รู้จักสองก้อนติดกัน**
ชื่อสองชื่อวางชิดกันไม่มีความหมายในภาษานี้ กฎเดียวนี้ตัดตัวเลือกขยะทิ้งมหาศาล

**ชั้นที่ 4 — ให้ไวยากรณ์เป็นคนตัดสิน**
ตัวตัดคำไม่ฟันธง แต่ส่งตัวเลือกหลายแบบให้ parser ลองแปลจริง
แล้วเลือกการตีความที่ใช้คีย์เวิร์ดมากที่สุด

```
ฟังก์ชันบวกเลขรับตัวแรกและตัวหลัง

  แบบ ก  ฟังก์ชัน │ บวกเลขรับตัวแรกและตัวหลัง             ← ฟังก์ชันไม่มีพารามิเตอร์
  แบบ ข  ฟังก์ชัน │ บวกเลข │ รับ │ ตัวแรก │ และ │ ตัวหลัง   ← ใช้คีย์เวิร์ดมากกว่า ✔
```

**ชั้นที่ 5 — พจนานุกรมที่เรียนรู้ได้**
ชื่อตัวแปร ฟังก์ชัน พารามิเตอร์ และตัวแปรลูป ถูกจำเข้าพจนานุกรม **ทันทีที่ประกาศ**
(ก่อนอ่านบล็อกย่อยด้วย) บรรทัดถัดไปจึงตัดคำถูกตั้งแต่ครั้งแรก
ยิ่งอ่านโปรแกรมไปเรื่อย ๆ ตัวตัดคำยิ่งแม่นขึ้น

### ชั้น NLP อื่น ๆ

* **คำพ้อง** — `แสดง / พิมพ์ / บอก / โชว์ / รายงาน` หมายถึงคำสั่งเดียวกัน
* **รวมวลี** — `มากกว่า หรือ เท่ากับ` ยุบเป็นตัวดำเนินการ `>=` ตัวเดียว
* **ตัดคำเสริม** — `ว่า นะ ครับ ค่ะ หน่อย` หายไปเองโดยไม่กระทบความหมาย
* **ความกำกวมตามบริบท** — `เท่ากับ` เป็นได้ทั้ง `=` และ `==` ตำแหน่งในประโยคเป็นตัวตัดสิน
* **เดาคำผิด** — พิมพ์ `แสด` แทน `แสดง` ระบบเดาให้พร้อมแจ้งเตือน

ทั้งหมดเป็น NLP เชิงสัญลักษณ์ (rule-based) ไม่ใช้โมเดล ML จึงเร็ว ผลลัพธ์คาดเดาได้
และไม่ต้องติดตั้งอะไรเพิ่ม — คอมไพล์ + รันไฟล์ 60 บรรทัดใช้เวลาราว 0.2 วินาที

## 8. วิธีขยายภาษา

### เพิ่มคำพ้องใหม่ — แก้ `thpro/lang/lexicon.py` ที่เดียว

```python
("PRINT", ["แสดง", "พิมพ์", "บอก", "โชว์", "ป่าวประกาศ"]),   # ← เติมคำท้ายรายการ
```

> ข้อควรระวัง: เลี่ยงสำนวนที่ขึ้นต้นด้วยคำสั่งอื่น เช่น อย่าใส่ `"ให้ผลลัพธ์"`
> เป็นคำพ้องของ `คืนค่า` เพราะจะชนกับ `ให้ผลลัพธ์เป็น...` (กำหนดค่าให้ตัวแปรชื่อ "ผลลัพธ์")

### เพิ่มฟังก์ชันสำเร็จรูป — แก้ `thpro/lang/builtins.py`

```python
BUILTINS = {
    "ตัดคำหน้า": ("_th_lstrip", "lstrip"),   # ชื่อไทย -> (โค้ด Python, ชื่อ helper)
}

HELPERS = {
    "lstrip": ("def _th_lstrip(text):\n    return str(text).lstrip()", ()),
}
```

### เพิ่มรูปประโยคใหม่ — แก้ `thpro/lang/grammar.py`

```python
Pattern("รอสักครู่",
        [Kw("WAIT"), Slot("วินาที", "expr")],
        lambda s, line, body: A.ExprStmt(
            A.Call(A.Name("รอ"), [s["วินาที"]]), line)),
```

รูปประโยคที่เฉพาะเจาะจงกว่า ให้วางไว้บนกว่าในตาราง

### ปรับสัญชาตญาณของตัวตัดคำ — แก้ค่าคงที่ใน `thpro/compiler/wordseg.py`
